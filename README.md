# GETPLUS

GETPLUS is an independent HSC 2027 and 2028 study workspace for Bangla, ICT and English.

## Preview and deploy

From the directory containing `index.html`, run `python -m http.server 8000` and open `http://localhost:8000/`. No package installation or build is required. Upload the directory contents to a static host. Keep `index.html` and `assets/` together. Hash routes work under a custom domain or a GitHub Pages project path.

The browser stores lesson progress, planner tasks, bookmarks and notes on the current device. There is no account system or cross-device sync.

## Course content and media

The nine short captioned MP4s, quizzes and revision notes are original GETPLUS study material. Official course and chapter links open Fahad Tutorials in a separate tab and keep its existing enrollment requirements. The site is independent and has no distribution arrangement with Fahad Tutorials. It contains no copies of that provider’s videos, artwork or private account information.

The course catalog lives in `assets/catalog.js`. To add owned or licensed lessons, add the lesson entry, encoded H.264 MP4 and matching English WebVTT file. Artwork uses original image-generated still lifes of a study desk and subject-specific objects. General Sans and Clash Display load from [Fontshare](https://www.fontshare.com/). The site uses system Bengali fonts where available.
